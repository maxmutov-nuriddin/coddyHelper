# 📜 Oltin Qoida: HTML

> [!IMPORTANT] Qat'iy Ko'rsatma
> - HTML hujjatning `<head>` bo‘limida `<link rel="stylesheet" href="styles.css">` yozib, CSS faylini to‘g‘ri (relativ yoki absolyut) yo‘l bilan ulashga e’tibor bering.  
- Fayl nomi va kengaytmasi (`.css`) aniq bo‘lishi, yo‘l harflarining kattalik/kichikligi (case‑sensitivity) va papka tuzilishi to‘g‘ri ko‘rsatilgan bo‘lsa, stil sahifasi muvaffaqiyatli yuklanadi.
